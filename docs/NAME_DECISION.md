# ScopeQuay naming decision

On 12 November 2026 the user explicitly requested replacing the previous personal
name with a product-oriented public name. ScopeQuay is the new public name for
the same research scope: risk-calibrated selective autonomy for tool-using LLM
agents. Scope describes the agent's authorized boundary; quay suggests a
controlled point where actions are prepared and launched.

The initial ActLatch candidate was rejected after the primary GitHub search
revealed a directly related existing project. ScopePilot and ScopeLatch also
have existing software uses. Exact-name GitHub search returned no ScopeQuay
repository in the preliminary check on 12 November. General web screening did
not surface an obvious exact-name product. These checks are not exhaustive
trademark, domain, package or legal clearance, and do not predict adoption.

Historic experiment logs, source snapshots and the earlier dossier retain their
original wording. The `tharun` Python namespace and internal controller IDs remain
as compatibility identifiers for the recorded research. New public entry points
use `scopequay`; this is a naming change, not a new empirical contribution.
No account memory update is claimed.

Primary screening endpoint:
https://api.github.com/search/repositories?q=scopequay+in:name
