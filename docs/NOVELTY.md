# Claim boundaries

Not new individually: action abstention, matched scenarios, five labels,
pre-execution judging, permission policies, recovery, risk-coverage trade-offs.

Potential contribution to test: risk-calibrated useful autonomy under a stated
severity loss budget, with executable counterfactual evaluation and secondary
recovery measurement. Actual benefit must survive matched-information baselines,
domain transfer and independent annotation.

Today's implementation is an engineering starting point: empirical threshold
selection plus deterministic interventions in a generic effect simulator. It does
not implement a mathematically guaranteed calibrated five-way controller, prove
novelty, or reproduce the performance of published competitors. A fully learned
minimum-cost intervention policy requires response/outcome models for clarify,
stage and escalation that the current terminal-intervention simulator lacks.

If strong gates match THARUN, remove superiority claims and investigate failure,
calibration and transfer boundaries without replacing the fixed project topic.
