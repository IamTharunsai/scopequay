# What a same-day implementation cannot establish

The working prototype, automatic checks and local experiments are concrete. The
complete 16-week study is not complete just because the software runs.

1. **Independent ground truth:** no second human has labeled these tasks. The
   blinded CSV is ready, not filled with an invented reviewer identity.
2. **Method:** there are now two executable candidates: score/threshold with rule
   interventions, and a five-way risk/cost/utility optimizer. The latter uses
   assumed costs and terminal interventions, not learned long-horizon human
   response outcomes. Neither has a proven statistical risk-control guarantee.
3. **Benchmark realism:** one generic effect ledger is not eight realistic domain
   environments. Need richer tasks, reversible/irreversible twins, paraphrases,
   action diversity, adversarial content and carefully validated oracles.
4. **Competitors:** installing a toolkit is not a valid fair benchmark adapter.
   A pinned AGT policy-engine slice now has real integration checks and logged
   runs. A pinned native Dogwood CLI point-policy slice now also has integration
   checks and logged test/transfer runs. Full toolkit runtime stacks, TS-Guard
   and tau-bench still need integration, contract checks and equal information access.
5. **Replication:** Llama is the current local benchmark model. Qwen's smoke is
   not a full second-model experiment. Hardware prevents treating all four local
   installed tags as a completed four-model study. No external vendor API runs.
6. **Statistics:** engineering fixture counts and bootstrap intervals do not prove
   a rare-harm guarantee. Power, label dependence and risk feasibility remain.
7. **Literature/paper:** primary-source abstracts/documents are recorded; full-text
   review and a final defensible contribution remain. The manuscript is a working
   source, not a submitted or accepted paper.
8. **Product/career:** no independent adopters, customers or scholarly impact have
   been manufactured. Those outcomes require actual external use and time.

Metric interpretation: the reported pooled useful-autonomy denominator includes
nominally feasible fault variants. The default recovery can safely halt after a
partial rollback, so completion is below one even for a perfect pre-action gate.
Use the domain/variant slices (especially normal vs fault variants) when assessing
that ceiling. Final paper endpoints must separate nominal capability, restraint
and recovery rather than attributing all completion loss to the gate.

The fixed topic remains THARUN. Negative results change the claim or method, not
the topic by stealth. Further implementation can proceed from the logged gaps.
