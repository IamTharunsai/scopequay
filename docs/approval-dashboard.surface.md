# Approval dashboard

Mode: Operate. Scope: local single-user business approval prototype.

## Direction contract
THESIS: put the request queue beside a readable action dossier so reviewing an
approval requires no navigation through research logs.
OWN-WORLD: extend the existing reports' navy, teal, white surfaces and system type;
use explicit text status alongside color. Standard buttons, filters and forms.
STORY: choose an illustrative request, inspect the proposed effect and reason,
resolve only what the decision permits, then inspect the persisted outcome.
FIRST VIEWPORT: navy navigation at left; queue with filters in the middle; selected
request, evidence, proposed tool call and approval controls to the right.
FORM: conventional master-detail business application; existing report identity
extended to an operational surface. Signature interaction: approval becomes an
ordered decision/effect trail beside the same request.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
