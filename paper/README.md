# Writing our research paper

The current public draft is [scopequay.md](scopequay.md), written for this project.
It is original prose grounded in the implementation, preserved evidence and linked
primary sources. Original writing does not remove the need to cite related work.
The old manuscript remains a historical local document; use the current public
draft going forward.

The claim ledger distinguishes observed facts, hypotheses, contradicted targets
and statements we must not make. Every empirical number needs a run, denominator,
data version and analysis provenance. Do not convert a software test into a
research result or the approval demo into a human study.

Before submission: confirm authorship, read closest papers in full, obtain real
independent annotation, validate environments and costs, preregister an untouched
confirmatory evaluation, perform meaningful replication, check every table and
citation, and complete independent review. These steps reduce error; they cannot
promise 100% accuracy or acceptance. No draft has been submitted or accepted.
